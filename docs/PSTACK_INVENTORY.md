# pstack inventory

This file lists every skill in the pstack set: the 24 `principle-*` skills, the other top-level skills, and the playbooks bundled inside `poteto-mode`.

When a new pstack skill is added, add a row here in the same change.

Three statuses:

- «مطبّقة» means this repo already did the skill, and the row names a pull request, a file, or a test.
- «ناقصة» means the skill applies to this ledger and has not been carried out. The row names the next step.
- «لا تنطبق» means this kind of project has no work for that skill. The reason says what the product is missing. "Not used" and "was not run" are not reasons.

Items that could be read either way stay in [For Ameer to decide](#for-ameer-to-decide).

Links are `https://github.com/ahlaljazera8-ctrl/ahl-aljazeera-accounting/pull/N`.
