# pstack inventory

This file lists every skill in the pstack set: the 24 `principle-*` skills, the other top-level skills (the playbooks and the rest), and the playbooks bundled inside `poteto-mode`.

When a new pstack skill is added, add a row here in the same change.

Status is «مطبّقة» only when this repo has a concrete trace: a pull request, a file, or a test. «لا تنطبق» means the skill's own trigger did not come up. Items that could be read either way are in [For Ameer to decide](#for-ameer-to-decide), not in the tables below.

The links are `https://github.com/ahlaljazera8-ctrl/ahl-aljazeera-accounting/pull/N`.
